## Getting Started

### Prerequisites

This is an example of how to list things you need to use the software and how to install them.
* npm
  ```sh
  npm install npm@latest -g
  ```

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/gobwah/portfolio_website2.git
   ```
2. Open a console in `/frontend_react` and install dependencies
    ```sh
    npm install
    ```
3. Optional: copy `.env.example` to `.env.local` and set `SANITY_API_READ_TOKEN` if the Sanity dataset is private. The project id defaults to the one in `sanity/env.js`.
4. Start the site
    ```sh
    npm run dev
    ```
    The site is on [localhost:3000](http://localhost:3000) and the Sanity Studio on [localhost:3000/studio](http://localhost:3000/studio).
5. The first time, add `http://localhost:3000` (and the deployed site URL) to the project's CORS origins on [sanity.io/manage](https://www.sanity.io/manage), under `API` > `CORS origins`, with "Allow credentials" checked, so the Studio can log you in.
